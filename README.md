# desinformation-et-malveillance-resourcepack

Resource pack d'un serveur Minecraft Java (26.3) entre amis.

Le jeu le télécharge tout seul à la connexion au serveur : il n'y a rien à installer à la main.

Chaque version est publiée en release (`desinformation-et-malveillance-resourcepack-vN.zip`), avec l'empreinte SHA-1 du zip dans les notes. Ce dépôt ne sert qu'à héberger ces zips : les sources sont ailleurs.
